# ЯДрышко (Core) + Шурик — семантика для Ozon

## Зачем Core в ozon-mebel

Шурик пишет **продающие** карточки; для SEO на Ozon нужны **частотные запросы** и LSI.  
**ЯДрышко** собирает семантическое ядро (Wordstat, кластеры, приоритеты), Шурик вшивает их в название, аннотацию и `#Хештеги`.

## Типовой сценарий

### 1. Семантика (Core)

```text
/core
Ниша: шкаф распашной белый 90 см для спальни и детской
Регион Wordstat: Россия (225)
Цель: продажи на Ozon, маркетплейс
Исключить: кухонный гарнитур, шкаф-купе, б/у, вакансии
Конкурент: https://www.ozon.ru/product/...
```

Результат:

```text
research/semantic-core-runs/ozon-shkaf-belyj-90-2026-05-23/
├── index.html
├── semantic-core.xlsx
├── 04-keywords-clean.csv
├── 05-clusters.csv
└── …
```

### 2. Карточка (Шурик)

```text
/shurik
Артикул: Ц0081444
Поставщик: https://...
Производитель: https://...
Семантика: research/semantic-core-runs/ozon-shkaf-belyj-90-2026-05-23/
Комната: Детская
```

Шурик берёт из прогона Core:

- топ запросы → начало **названия** и **аннотации**;
- кластеры P0 → **#Хештеги** (20–30);
- long-tail → блок «Подойдёт, если ищете…»;
- в `_meta.seo_keywords` в `row.json` — список через запятую.

Чеклист полей: `docs/ozon-seo.md`.

### 3. Серия Mori (несколько артикулов)

Один прогон Core на **серию** (общие ключи), затем Шурик по каждому артикулу с уточнением размера/модели.

## Серия только для Ozon (без сайта)

Core рассчитан на сайты, но для маркетплейса задайте **нишу как товарную категорию**, без URL:

```text
/core
Тема: корпусная мебель, шкафы распашные, бренд ДСВ серия Mori
Регион: 225
Приоритет запросов: коммерческие (купить, цена, размер)
```

В `00-brief.md` укажите: «канал продаж — Ozon, не SEO сайта».

## Сборка отчётов (скрипты)

После заполнения CSV в папке прогона:

```bash
py scripts/build_core_html_report.py research/semantic-core-runs/<папка>
py scripts/build_semantic_core_xlsx.py research/semantic-core-runs/<папка>
```
