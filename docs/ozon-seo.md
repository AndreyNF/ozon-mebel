# SEO для карточек Ozon (мебель)

Чеклист для каждой карточки в `cards/{АРТИКУЛ}/`.

## 1. Название товара (col 3)

- В начале — **главный запрос** (тип + цвет + размер): «Шкаф белый 90 см распашной…»
- Далее: бренд, модель, ключевые атрибуты (двери, ящики, материал)
- Комнаты/назначение в конце: «для спальни и детской»
- Без CAPS, без «лучший/№1», без дублей слов
- Ориентир: до ~150–200 символов, читаемо человеку

## 2. Аннотация (col 28)

- Первый абзац — **ответ на запрос** + модель + размеры
- 3–5 буллетов с УТП и LSI-словами (материал, планировка, серия)
- Блок «Размеры / производитель / гарантия»
- Закрытие: «Подойдёт, если ищете…» с 2–3 long-tail фразами
- Ключи **естественно**, без спама

## 3. #Хештеги (col 27)

- 20–30 тегов через пробел: `#шкаф #шкафбелый …`
- Тип, размер, комната, материал, бренд, серия, стиль
- Только релевантные запросы (не «шкаф-купе» для распашного)

## 4. Атрибуты

- **Особенности**, **Комната**, **Назначение** — из Wordstat/конкурентов
- **Модель объединения** — серия для склейки карточек
- **Объединить в похожие** — семейство линейки

## 5. Rich-контент

- Заголовки виджетов с ключами (размер, тип, комната)
- `alt` у изображений — описание товара, не «фото 1»
- Тексты chess/billboard дублируют запросы из названия

## 6. Фото

- Имена файлов: `01-main`, `02-infographic` — порядок в галерее
- Инфографика с размерами и УТП — индексируется в Rich

## 7. Мета в row.json

```json
"_meta": {
  "seo_keywords": "запрос1, запрос2, …"
}
```

## Сборка после правок

```powershell
py scripts/build_rich_content.py {АРТИКУЛ}
py scripts/build_upload_excel.py {АРТИКУЛ}
```

## Источники семантики

- Wordstat (MCP KV) — частотность
- Топ-3 карточки конкурентов на Ozon — title + буллеты
- Подсказки Ozon в шаблоне категории
