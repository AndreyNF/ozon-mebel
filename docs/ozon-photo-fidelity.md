# Фото Ozon: не выдумывать товар

Краткая выжимка для людей. Для агента: `.cursor/rules/ozon-photo-fidelity.mdc`.

## Суть

Нейросеть **обрабатывает** фото производителя (i2i), а не рисует «идеальную мебель с нуля».

## Разрешено

| Что | Пример |
|-----|--------|
| Студийный фон | Белый фон для главного фото |
| Интерьер | Та же стенка в гостиной |
| Люди | Открывают шкаф, пользуются кухней |
| Инфографика | Размеры, состав комплекта |
| Свет/резкость | Улучшение без смены цвета |

## Запрещено

| Что | Почему |
|-----|--------|
| Лишние шкафы, модули, полки | Не соответствует комплекту SKU |
| Три типа плит на кухне (газ/электро/индукция) | Достаточно одного кадра зоны варки — см. `ozon-photo-series-10.mdc` |
| Другая раскладка гарнитура | Модерация «не соответствует товару» |
| Яркий/чужой цвет | Жалобы покупателей, возвраты |
| Text-to-image без референса | Выдуманный товар |

## Инструменты

- MCP: `gpt-image-2`, `seedream-4_5-edit` с `input_urls`
- Браво: `scripts/bravo_faithful_i2i_prompts.py`
- Sanvut кухня: `scripts/sanvut_faithful_i2i_prompts.py`
- Манифест: `"photo_policy": "dealer_i2i_faithful_color_layout"`
