# Маршрутизация категорий Ozon (корпусная / кухня)

Шурик **оценивает категорию до заполнения** Excel и фиксирует решение в `{АРТИКУЛ}.md` (раздел «Категория Ozon»).

---

## Принцип

| Направление | Раздел Ozon (типично) | Excel в репозитории |
|-------------|----------------------|---------------------|
| **Корпусная мебель** (основной поток) | Комплекты мебели, шкафы, кровати, комоды… | `templates/Комплекты мебели_21.05.2026.xlsx` |
| **Кухонная мебель** | Кухонные гарнитуры, кухонные столы/стулья, модули… | **отдельный шаблон** — добавить при появлении; не подставлять в «Комплекты мебели» без проверки |

`DESCRIPTION_CATEGORY_ID` для текущего шаблона: **80770870** (`template-category-meta.json`).

---

## Быстрая классификация по источникам

### → Кухонная мебель (отдельный раздел)

Ключевые слова и типы:

- кухонный гарнитур, кухня, кухонный модуль, напольный/навесной кухонный шкаф;
- кухонный стол, кухонный стул, табурет кухонный;
- кухонная полка, остров, буфет, обеденная группа для кухни;
- столешница, фартук, мойка в составе комплекта (если продаётся как кухонный комплект).

**Действия Шурика:**

1. Пометить: `Категория Ozon: Кухонная мебель (уточнить тип в справочнике)`.
2. Промпты фото: блок **Кухня** в `docs/prompts-by-category.md`.
3. Если в репозитории нет xlsx для кухни — заполнить `{АРТИКУЛ}.md` и `row.json` **частично**, в заметках: «нужен шаблон категории Кухня; не загружать файл Комплекты мебели».

### → Корпусная мебель (текущий шаблон)

- шкаф распашной, шкаф-купе, пенал, гардеробная;
- кровать, двухъярусная кровать, основание;
- комод, тумба прикроватная, стол письменный, ТВ-тумба;
- стеллаж, полка настенная (не кухонная);
- прихожая (обувница, вешалка, модуль прихожей);
- детская мебель (кровать, парта, стеллаж);
- офисный стол, офисное кресло, тумба под принтер.

**Действия:**

1. `Категория Ozon: Комплекты мебели` (или уточнённый **Тип** из справочника категории).
2. Поле **Тип** (col 23) — значение из справочника Ozon для этой категории.
3. **Комната** (col 40) — для SEO и промптов (Спальня, Детская, Прихожая…).

## Если категория спорная

1. Открыть карточку **конкурента на Ozon** (ссылку даёт пользователь).
2. Скопировать **тип товара** и структуру названия.
3. В `{АРТИКУЛ}.md` записать:

```markdown
## Категория Ozon (решение)

- **Выбрано:** …
- **Обоснование:** …
- **Альтернатива отклонена:** …
- **Источники:** производитель / поставщик / конкурент
```

4. При сомнении между корпусом и кухней — **не** использовать «Комплекты мебели» для явной кухни.

## Корпусная: подтипы (для названия и SEO)

| Подтип | Акцент в продающем тексте |
|--------|---------------------------|
| Шкаф | объём, планировка, зеркало, нагрузка полок |
| Кровать | размер спального места, нагрузка, без матраса/с матрасом |
| Комод / тумба | ящики, габариты под нишу |
| Стеллаж | полки, нагрузка, крепление |
| Детская | безопасность, углы, возраст |
| Прихожая | узкий коридор, обувь, вешалки |

Кухня — отдельные УТП: влагостойкость, фурнитура, столешница, размер под нишу.
