# Производитель: Браво Мебель (tdbravomebel.ru)

Реестр машиночитаемый: `data/manufacturers/bravo-mebel.json`  
Проверка дублей: `py scripts/bravo_card_registry.py check URL`

## Триггер для агента

Пользователь кидает **ссылку на tdbravomebel.ru** (коллекцию или раздел) → **без уточняющих вопросов**:

1. Проверить реестр — карточка уже есть? → **стоп**, сообщить `product_id` / папку.
2. Если нет — полный пайплайн до `ozon_api_import.py` (см. `.cursor/rules/ozon-new-card-pipeline.mdc`).
3. После успешного import — **дописать** запись в `bravo-mebel.json` → commit.

## Правило «сколько карточек»

| URL на сайте | Карточек Ozon |
|--------------|---------------|
| `/collections/...` — готовый гарнитур (N предметов) | **1** (артикул = название коллекции) |
| Отдельный модуль «Гориция НСМ (Цвет) - …» | **1** только если пользователь явно просит поштучную продажу |
| Корень сайта / каталог целиком | Сначала **инвентаризация** коллекций, затем по 1 карточке на гарнитур |

**Не дублировать:** модули из состава уже опубликованного гарнитура не выгружать отдельно, пока нет отдельной задачи.

## Особенности Браво

- **Цвет:** только с фото **того же** цвета коллекции. На странице tdbravomebel часто смешаны кадры других расцветок — **не брать первый JPEG подряд**.
- **Фото:** `py scripts/bravo_dealer_photos.py` — скачать с дилера, 3:4 PNG, **без AI**. Не «приукрашивать» сапфир в яркий глянец.
- **Главное фото:** lifestyle/студия дилера с правильным цветом (не AI-рендер).
- **Модульные гарнитуры:** габариты в Ozon — по **композиции на фото** коллекции, не сумма всех модулей в линию.
- **НСМ** в названии — направляющие скрытого монтажа (не отдельный SKU).
- **Бренд Ozon:** `Браво`.
- **Вес/упаковка:** для комплектов — сумма модулей; при баннере «Некорректные габариты и вес» в ЛК — сверить с чертежами дилера или дождаться замеров OBX.
