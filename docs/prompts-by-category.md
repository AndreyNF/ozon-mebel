## Как Шурик выбирает категорию

1. Явное указание пользователя («это кухня»).
2. Категория Ozon / тип товара в шаблоне.
3. Ключевые слова в описании производителя (кровать → Спальня, шкаф-купе → Шкаф).
4. Если неясно — **Спальня** или **Гостиная** по умолчанию для универсальной мебели; в карточке указать `[Категория интерьера: уточнить]`.

В промпте заменяй `[ТОВАР]` на краткое описание: «white metal bunk bed Sevilla», «corner kitchen cabinet 2.4m oak».
