# Требования Ozon к фото товара (мебель)

> Сводка для Шурика и генерации через `gpt-image-2`. При расхождении с ЛК Ozon — приоритет у актуальных правил в [seller-edu.ozon.ru](https://seller-edu.ozon.ru).

## Технические параметры

| Параметр | Значение для мебели |
|----------|---------------------|
| **Форматы** | JPEG, JPG, PNG, WEBP, HEIC |
| **Соотношение сторон** | **3:4** (вертикаль) — универсальный стандарт Ozon с 2025 г.; квадрат 1:1 ещё встречается в старых карточках, но для новых — **3:4** |
| **Рекомендуемое разрешение** | **1500×2000 px** и выше (например 2000×2667) |
| **Допустимый диапазон** | от 200×200 до 4320×7680 px |
| **Размер файла** | до **10 МБ** |
| **Количество** | до **15** фото (1 главное + до 14 доп.) |
| **Генерация Шурика** | `aspect_ratio: "3:4"`, `resolution: "2K"` (или `4K` для инфографики) |

## Главное фото

- Товар **полностью** в кадре, узнаваем за 1–2 секунды.
- Для **мебели** Ozon рекомендует показывать товар **в интерьере** или на **чистом нейтральном фоне** (студийный свет).
- Без водяных знаков, чужих логотипов, цен, скидок, контактов, «Купи сейчас».
- Без 3D-рендеров «из воздуха», эскизов, ч/б, размытия.
- Без «домашних» кадров: ковёр, беспорядок, посторонняя мебель, жёсткие тени.

## Дополнительные фото

- Инфографика **разрешена** и полезна: размеры, материалы, нагрузка, комплектация.
- Текст на инфографике — **крупный**, контрастный, без цен и CTA.
- Все кадры должны соответствовать названию и описанию карточки.
- Для мебели с механизмами — показать трансформацию / ящики / раздвижение.

## Запрещено на фото

- Цены, акции, «−50%», телефоны, ссылки, QR.
- Коллаж «непонятно что продаётся».
- Фото без самого товара.
- Чужие карточки без прав (референс — только для генерации, не копировать 1:1).

## Настройки MCP `gpt-image-2` для Ozon

```json
{
  "aspect_ratio": "3:4",
  "resolution": "2K",
  "input_urls": ["URL референса"]
}
```

- Если есть фото производителя или конкурента — **всегда** `input_urls`.
- Главное и lifestyle — реалистичный свет, без «AI slop».
- Инфографика — минимум текста на **русском**, только факты из карточки.
