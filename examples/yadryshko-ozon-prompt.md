# Примеры запросов `/core` для Ozon (мебель)

## Шкаф распашной

```text
/core
Ниша: шкаф распашной белый 90 см, 2 двери, с ящиками, для спальни и детской
Регион Wordstat: Россия, ID 225
Цель: продажи на Ozon
Исключить: шкаф-купе, кухня, б/у, ремонт своими руками
Конкурент Ozon: https://www.ozon.ru/product/...
```

## Серия Mori (ДСВ)

```text
/core
Тема: корпусная мебель серия Mori ДСВ — шкаф, кровать, комод, детская
Регион: 225
Приоритет: коммерческие запросы с размером (90 см, 180 см)
Исключить: вакансии, бесплатно, чертёж DIY
```

## Кухня (отдельный раздел Ozon)

```text
/core
Ниша: кухонный гарнитур угловой, ЛДСП, малый метраж
Регион: 225
Цель: Ozon, категория кухонная мебель
Исключить: корпусный шкаф в спальню
```

После прогона — передать папку `research/semantic-core-runs/...` в запрос **Шурику** (`docs/yadryshko-ozon-mebel.md`).
